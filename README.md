# merchly-linkedin-assets

Images for Merchly's LinkedIn company page posts, generated by `make_image.py`
(1080x1080 PNG, Merchly brand style) and attached to posts through Buffer.

- `make_image.py` — generator. Types: workflow, checklist, compare, statement. See the docstring.
- `images/YYYY-MM-DD-slug.png` — one image per post that uses one.

No code secrets or customer data live here.

## Designer-grade renderer (preferred)
`render_html.py` renders visuals from HTML/CSS with headless Chrome: 4:5 (1080x1350, exported at 2x as JPEG),
light/dark themes, icons, highlighted keywords, charts, myth/fact, grids, timelines, compare tables and PDF carousels.
`make_image.py` is the older Pillow renderer, kept as a fallback if Chrome is unavailable.
